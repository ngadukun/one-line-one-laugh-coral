An entry for the [One Line, One Laugh](https://make.fun/c/u-coral-404-one-line-one-laugh-22f2c9f3) competition on make.fun.

## What it does

`main.ts` writes a single original one-liner (at most 200 characters) to
`/output/entry.txt`. A judge model compares the lines two at a time and the
funniest line wins.

## Run it

```sh
node main.ts
```

It validates the line (non-blank, one line, 200 characters or fewer) and
writes it to `/output/entry.txt`.
